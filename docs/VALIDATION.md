## 复现测试

```sh
cd node
npm ci
npm test
cd ../go
./bin/setup
go test -race ./...
go vet ./...
cd ..
python3 scripts/smoke-go.py
```

Node 需 24.x；Go 需 1.26.3 或兼容更高版本。smoke 使用临时根目录和假凭证，强制排除当天检测窗口，不发送真实通知、不注册服务。

测试覆盖时间边界、轮播排除、字段错误、持久化去重、晚到开播时间、下一场、重试与 TTL、Webhook 签名及业务错误、私聊 token 更新、锁协议互通、Node 状态格式兼容、官方签名/压缩帧/认证/房间校验/会话清理、预检/停止顺序/回滚拒绝与最新状态带回。

需要真实通知时另行配置权限 600 的 .env，执行对应入口的 test-notification；此命令会真实发送，不是普通单元测试。真实云切换、手机通知、电脑重启和平台开播事件分别验收，不能用构建或 API 成功替代。
